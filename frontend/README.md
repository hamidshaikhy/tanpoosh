# TANPOOSH frontend

Next.js 16.4 App Router, React, TypeScript, Tailwind, TanStack Query and Zustand. All customer and management copy is Persian and RTL.

Run the complete application with the root `START_TANPOOSH.cmd` launcher and use **http://localhost:8088**. The reverse proxy routes API/media requests to Django; opening port 3000 directly does not reproduce the complete application origin.

Setup, verification and safe build commands: [QUICKSTART](../QUICKSTART.md). Photograph studio contract: [STUDIO_IMAGES](../docs/STUDIO_IMAGES.md). Follow [AGENTS.md](AGENTS.md) and the bundled Next documentation when editing Next code.
